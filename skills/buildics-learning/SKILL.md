# BUILDICS Learning

1. Link finding, proposal, approval, action and outcome using correlation and record IDs.
2. Compare predicted vs observed outcomes with explicit observation windows, baselines, confounders and missing-data flags.
3. Track acceptance/rejection reasons, false alarms, time-to-acknowledge, time-to-resolve and recurrence only when underlying data supports them.
4. Produce recommendations for threshold/rule improvements with before/after tests and human review.
5. Do not autonomously update live rules, models, device parameters or permissions. Preserve audit history and version changes.
6. Export evidence-linked outcome records compatible with ../../contracts/common-data-contract.md.
